# Unity application

C# headset application. The #45 spike project is `spikes/openxr/`, pinned to
Unity **6000.6.0f1 (f7f8ed4d1e24)**, OpenXR **1.18.0**, and Unity OpenXR: Meta
**2.6.1**. Its README and the O5.1.3 runbook describe both build variants.
Phase 1 experiments precede production application features and G1 approval.
