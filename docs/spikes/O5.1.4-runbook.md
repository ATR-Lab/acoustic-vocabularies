# O5.1.4 — G1 / Dex3 import and pose validation

The converter/importer is ready. Vendoring STL binaries is blocked while Git LFS
is unavailable; raw assets and generated Unity meshes remain ignored. Review the
external methodology copy before accepting proposed tolerances or timing criteria.

## Reproduce the import

From repository root, using Python 3.12 and the editor pinned by #45:

```powershell
python spikes/O5.1.4/fetch_meshes.py
python spikes/O5.1.4/convert_urdf.py unity/Assets/ThirdParty/Unitree/G1/g1_29dof_with_hand_rev_1_0.urdf --mesh-root external-assets/unitree-g1 --output external-assets/converted-g1
python spikes/O5.1.4/convert_urdf.py unity/Assets/ThirdParty/Unitree/G1/g1_29dof_with_hand_rev_1_0.urdf --mesh-root external-assets/unitree-g1 --output external-assets/converted-g1-repeat
```

Expected: 49 checked meshes, 53 links, 43 revolute joints, 629338 mesh triangles.
Both runs must give description SHA-256
`6ff5a6f555cb650e628fff674d28827df6f8fb4618afcb61506c0f868d1cbb41`.
The mesh format has magic `AVM1`, little-endian triangle count, then nine float32
coordinates per triangle. Vertices are converted from ROS to Unity `(-y,z,x)`;
winding is reversed once. URDF origins and axes remain in source coordinates in
JSON. The editor converts fixed-axis RPY and joint axial vectors consistently.

Set ignored environment `G1_DESCRIPTION_JSON` to the generated description path.
Open the Unity project, then choose **Spikes > URDF > Import from local environment
path**. Alternatively run the editor headless with `-batchmode -nographics
-projectPath <project> -executeMethod AcousticVocab.Spikes.Urdf.Editor.UrdfSpikeImport.Import
-quit -logFile <ignored-log>`. Use the same quoting and process-local temp setup
as the #45 build wrapper. Expected marker:
`URDF_SPIKE_IMPORTED links=55 driven_joints=43 rendered_triangles=629338`.

The authored USD fixed-frame metadata in `docs/spikes/urdf/usd-fixed-frames.json`
corrects the empty mid360 sensor frame and adds two empty hand-camera frames.
Original URDF geometry and all 43 driven-joint coordinates remain unchanged.
For baseline reproduction only, set `G1_SOURCE_ONLY_IMPORT=1` to import the 53
source links without those corrections; unset it before the aligned comparison.

The committed wrapper supplies these flags and keeps logs ignored:

```powershell
./spikes/O5.1.4/invoke-unity.ps1 -EditorPath $env:UNITY_EDITOR -Action Import
```

The importer creates ignored `Assets/Generated.local.data/G1/G1Preview.unity` and
a prefab. It starts from the same seated workcell, disables the synthetic robot,
and places the G1 pelvis 0.75 m above the floor facing the observer. It does not
save over the committed #45 scene. It embeds the BSD-3 license in Resources.
Meshes are displayed without colliders or physics. No decimation is applied yet.

## Map actual simulator joints

Obtain the actual loaded-articulation `joint_inventory.csv` from #44, not a guessed
URDF count or a Python config list. Preserve its index order:

```powershell
python spikes/O5.1.4/build_joint_map.py external-assets/converted-g1/g1_description.json .local/isaac/joint_inventory.csv --output .local/urdf-mapping
```

The map generator defaults to a name-matched candidate table using the observed
#44 inventory. `candidate_sign=1` and `candidate_zero_offset_rad=0` begin as
hypotheses, with `pose_verified=false`. The committed table has subsequently passed
the full recorded 92-pose comparison. To reproduce that verified table after the
comparison command below, pass `--verified-pose-summary docs/spikes/urdf/pose-summary.json`
to the generator; an incomplete/failing comparison is rejected. The runtime method
`RobotHierarchy.ApplyJoint(name, radians)` uses URDF coordinates and rejects
unknown/nonfinite input. It does not silently clamp differing simulator limits.
Do not treat this API as the approved production state map before pose validation.

## Full pose comparison

Use #44's exporter for **92 poses**: default, each of 43 joints individually at 25%
and 75% of its range, and five deterministic engineering spread poses. These are
engineering fixtures, not study randomization seeds. Export actual measured q,
root position and quaternion, and actual link/body world transforms.

Input JSON contract: `coordinate_frame: usd_world_rh_z_up`, and `poses` with
`name`, `joint_names`, `joint_positions` (actual radians), `root_position` (meters),
`root_quaternion_wxyz`, and `links` containing `name`, `position`,
`quaternion_wxyz`. USD merged/fixed links absent from the articulation body API
must remain explicitly unobserved. Do not invent their measurement poses.

Set ignored `G1_POSES_JSON` to the Isaac export and `G1_UNITY_POSES_JSON` to a local
output path. Run **Spikes > URDF > Export comparison poses** or headless
`-executeMethod AcousticVocab.Spikes.Urdf.Editor.UrdfSpikeImport.ExportPoses`.
Expected marker: `URDF_SPIKE_POSES_EXPORTED poses=92 links=55`.
The exporter replaces the scene placement with the measured root pose, applies
the same measured joint vector, then converts Unity world transforms back to USD
RH Z-up. This prevents table placement from contaminating coordinate comparisons.

```powershell
./spikes/O5.1.4/invoke-unity.ps1 -EditorPath $env:UNITY_EDITOR -Action ExportPoses
```

```powershell
python spikes/O5.1.4/compare_poses.py .local/isaac/poses.local.json .local/unity-poses.local.json --output .local/pose-comparison
python -m unittest discover -s spikes/O5.1.4 -p 'test_*.py'
```

Expected output is **measured**, not prescribed: per-link errors and maximums,
missing Unity links, unobserved Unity links and whether all observed links meet
the proposed <=5 mm / <=1 degree tolerance. Quaternion comparison is sign-invariant.
Never turn missing reference links into zero errors. Investigate any failure before
changing candidate signs/offsets; preserve source hashes and the failed comparison.
Capture side-by-side views at at least three poses, including hand closure, with
the operator and verify the coordinate alignment visually.

For Unity's rendered half, set `G1_CAPTURE_POSES` to a comma-separated list of
three exact names from the measured export and `G1_CAPTURE_DIRECTORY` to an
ignored local directory. Include a hand-closure/spread pose. Run:

```powershell
./spikes/O5.1.4/invoke-unity.ps1 -EditorPath $env:UNITY_EDITOR -Action CaptureComparisonImages
```

This action uses the graphics device and omits `-nographics`. Expected marker is
`URDF_SPIKE_IMAGES_RENDERED count=3`. It renders engineering screenshots, not
Quest captures or wearer evidence. Keep PNGs local while LFS is unavailable.
For close hand views, set `G1_CAPTURE_FOCUS_LINKS` to
`left_hand_palm_link,right_hand_palm_link`. The camera fits each palm and its
finger geometry independently, writes a separate image per hand and pose, and
logs the exact camera/target positions in USD coordinates for matching Isaac
views. Use a separate measured hand-flexion fixture with the body neutral so
the arms do not obscure the fingers. Keep that supplemental fixture and its
comparison separate from the canonical 92-pose results.
To match an Isaac camera exactly, set `G1_CAPTURE_VIEW_JSON` to a local JSON file
with `camera_position_usd`, `target_position_usd`, `width`, `height`,
`vertical_fov` (degrees), `near_clip` and `far_clip` (meters). This overrides the
automatic camera position. The supplemental shared hand view uses 1280x720,
eye `[1.1,-0.15,1.1]`, target `[0.32,0,0.84]`, focal length 24 mm with a 36 mm
horizontal aperture (vertical FOV approximately 45.747 degrees), and 0.1/100 m
clipping planes. Different rendering materials and lights are not pose errors.
