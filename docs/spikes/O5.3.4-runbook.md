# O5.3.4 state source verification

Use the pinned Unity editor and the approved built-in test packages. From the
repository, run:

```powershell
./tools/build-unity.ps1 -Unity <unity-executable> -Target Test -ProtocolVersion engineering-pending-review -BuildId state-edit-tests
./tools/build-unity.ps1 -Unity <unity-executable> -Target TestPlayMode -ProtocolVersion engineering-pending-review -BuildId state-play-tests
```

Use a new build ID each time. The wrapper discovers only project test assemblies
for the chosen platform and refuses an empty run. Participant builds use
`BuildOptions.None`; play-mode test assemblies are excluded from their source
audit through Unity's `PlayerWithoutTestAssemblies` API.

For the optional actual-recorded-contract test, privately set
`STATE_SOURCE_EVIDENCE` to a directory containing:

- `layout.json`: exact layout used for that run.
- `reset-check/neutral_v1.json`: actual captured, hash-verified #53 snapshot.
- `publisher-check/sample-first.json` and `sample-last.json`: retained real
  version 2 wire samples with the same station and scene identity.

The test loads all 43 joints and 60 objects through the C# parser. An unprotected
rate-run sample is not a neutral-parity measurement. Keep that limitation with
the result and do not substitute synthetic fixtures for actual recordings.

For a headset run, provision the #59 station config and the separate private
source config/neutral asset with measured hashes. Use the authorized isolated
station endpoint and approved clock evidence. Record a fresh 30-minute run with
`robot_state_source=live`, retaining sample-age CSV, events, build identity,
scene/layout/neutral/config hashes and every stale interval. Keep raw artifacts
private and publish only sanitized counts, percentiles and hashes.

At a safe boundary, request an independently logged backend reset. Confirm the
live source's rendered state and latest sample match the stored neutral before
enabling the next cue. Repeat with `robot_state_source=snapshot` using the same
app binary, then compare all joint/object states and matched neutral captures.
Changing source must require only station provisioning, not a rebuild.

Deliberately test 200 ms, 300 ms and 2-second gaps with the harness first. On the
real headset, measure the actual injected interval and compare event duration
within one observed render frame. Do not infer real timing from a virtual test
clock. Corrupt a copied snapshot/trajectory byte and verify `HASH_MISMATCH`,
a logged fault and no cue readiness. Restore the verified artifact explicitly.

The #56 trajectory recorder supplies the eight orientation and 32 execution
files plus their private hash index. Do not fabricate those recordings or claim
teaching playback validation before actual Isaac captures exist.
