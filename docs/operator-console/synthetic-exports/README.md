These are **public synthetic examples**, generated with the explicit DEMO engine,
illustrative five-slot clocks and a fixed synthetic calendar. They do not record
participant checks, device state, exposure or an actual visit. Run-sheet headers
use the reviewed #32 oracle; deviation headers remain provisional until the
external protocol template is supplied. Blank block timestamps are intentional.
The machine-readable hash manifest is generated from the committed UTF-8 bytes.
