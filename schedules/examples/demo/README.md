# DEMO example outputs (synthetic)

These files were generated by `python -m av_schedules demo-examples` from the public
seed `DEMO-o4.4.1-example`. They are format and balance examples only: they are not
study material and must never be used with participants. Every JSON file carries
`"demo": true`.

Contents, per study (`A/`, `B/`):

- `<set>-batch-table.csv` (Study A) or `<set>-design-table.csv` (Study B) for the pilot
  and the confirmatory-sized sets (A: 3 and 18 batches; B: 8 and 64 + 8 spare dyad slots).
- `<set>-balance.csv`: the balance report.
- `<set>-manifest.json`: SHA-256 of every file of the set, including the unit folders
  that are not committed here.
- One unit folder each (`A/A-C01/`, `B/B-C01/`) with `curriculum.csv` and
  `permutation.json`.

`tests/schedules/test_schedules_io.py` regenerates the examples and fails if any byte
differs. Real pilot and confirmatory outputs are generated from a private master seed
into `schedules/out/` (git-ignored) and kept in restricted storage.
