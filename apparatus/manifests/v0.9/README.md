# Provisional apparatus manifest v0.9 tooling

The public repository contains the strict schema and synthetic examples only.
Actual per-station manifests contain private settings and allocation information
and must remain in ignored private storage. See
[the collector runbook](../../../docs/apparatus-manifest.md).

The exact read-only methodology template is unavailable. The current schema is
derived from issue #83 and cannot claim a completed pilot apparatus freeze,
accepted release candidate, G4 approval or station qualification.
